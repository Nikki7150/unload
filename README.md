# Unload 

## Description
I've always not been able to finish a journal because I felt it to be too tedious to open a book and use a pen to write down my feelings in the moment. I always felt too overwhelmed to even pick up a pen to write something down. The only thing that helped me was typing and coding. So thats what i did. I sat and wrote my thoughts into my notes app. 
But that felt way too impersonal and unsafe. And I always had to click on create a new note and then start writing and save it. And most of the times, I wouldn't be able to find that specific note either. 
This is why I thought of this app. I wanted to make it such that when i open the website, I'm prompted with just dumping everything im thinking about. I wanted to make it such that after i dump into one entry and save, I can write another entry right after, without having to worry about organizing or clicking on add new note to write another entry. 
I wanted this website to feel almost automatic. I had been wanting to build a website that used AI to sort my thoughts on its own in the background without me having to worry about it. And thats exactly what I made in this website with the Google Gemini API key. As soon as i save an entry, the backend takes the entry to the AI, finds a perfect general topic for it to be saved under, and saved the entire note. 
This made it easier for me to search through by topic for all my entries. 
But what about when I remember I had written about a certain app idea I had and it got lost in my notes? Those general topics would be of no help since they were too "genertal" and wouldn't save according to app idea. So I came up with the idea to use a search bar where you can write just one word and the backend searched through all your entries, finds all the entries with that word in it and shows it to you. A lot simpler right? 
It made my heart so full when I finished this website. And I have started using it too. I just saved it onto my mac as a favorite site and have started writing a bunch of my thoughts as well as all my app ideas and design ideas and I've been enjoying it. I hope you like it too. 

## Features
- Login using email, password, and username
- Website always opens on the wntry page, when logged in, so you can start dumping your thoughts immediately
- Write a title and dump your thoughts and hit Submit and you're done
- The website handles everything else
    - it generates a general topic for that entry and saves it.
- You can flip to the Journals page to find all your saved thoughts with their very own topics generated by Gemini AI logic
- Use the search bar to write a specific word that you remember from a journal entry and enter.
    - The page will show you exactly which journals have that word in it for you to easily find what you are looking for
- you can use Topic Filters to filter all your notes by the topic it is saved under
- Click on the entry you want to read and it will open up on the right page.
- You can edit both the title as well as the entry itself and save. The topic generator will run again to see if you made major changes and if it has to change the topic to something else based on the new content.
- You can delete the note, but remember: once you delete it, it will be lost forever. You will get another popup asking if you really want to delete the entry and that is the only chance to save it.
- You can flip to the profile page with the user tag and see your Username, email signed in with and the day you started to journal in the website.
- You can also add your own custom profile picture in that screen and it will persist.

## How to Set up Locally
### Prerequisites
- Python 3.10+
- Node.js 18+
- A PostgreSQL database (eg., free neon Project, free Supabase project)
- A Google Gemini API key (free tier)

### Backend Setup
1. Move into backend folder and create a virtual environment
```bash
   cd backend
   python3 -m venv .venv
   source .venv/bin/activate   # on Windows: .venv\Scripts\activate
```

2. Install dependencies
```bash
   pip install -r requirements.txt
```

3. Create a `.env` file inside `backend/` with the following:
```
   DATABASE_URL=your_postgres_connection_string
   GEMINI_API_KEY=your_gemini_api_key
   SECRET_KEY=any_long_random_string
```
   A random `SECRET_KEY` can be generated with:
```bash
   python3 -c "import secrets; print(secrets.token_hex(32))"
```
 
4. Start the server:
```bash
   uvicorn main:app --reload
```
   The API will be running at `http://127.0.0.1:8000`. Tables are created
   automatically on first startup.

### Frontend Setup
1. In a separate terminal, move into the frontend folder and install
   dependencies:
```bash
   cd frontend
   npm install
```
 
2. Create a `.env` file inside `frontend/` with:
```
   VITE_API_URL=http://127.0.0.1:8000
```
 
3. Start the dev server:
```bash
   npm run dev
```
   The app will be running at `http://localhost:5173`.

## Notes
- the backend's CORS settings (in backend/main.py) currently allow `http://localhost:5173` - update `allow_origins` if you run the frontend on a different port or host
- Uploaded profile pictures are stored on local disk under `backend/uploads/` and are not committed to version control.
